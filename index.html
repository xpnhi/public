Command Cheat Sheet

SSH & YubiKey

Test GitHub Connection

ssh -T git@github.com

Load YubiKey into SSH Agent

eval "$(ssh-agent -s)"
ssh-add ~/.ssh/id_ed25519_sk

Git Workflow

Clone via SSH

git clone git@github.com:xpnhi/configs.git

Standard Push

git add .
git commit -m "Update configs"
git push -u origin main

Advanced Git

Sparse Checkout (Download only vim-unix folder)

git clone --filter=blob:none --sparse git@github.com:xpnhi/configs.git
cd configs
git sparse-checkout set vim/vim-unix
