Technical Reference: Updating Hugo Congo Favicons

April 24, 2026·1 min

Changing the site icon in the Congo theme requires specific file naming and directory placement to override the default theme assets. This guide documents the process for a Debian-based Hugo environment.

1. Prepare the Assets #

Generate or select a square image (PNG). You need to create several copies with specific names that modern browsers and the Congo theme expect.

Run these commands in your static/ directory:

cd ~/hugo-notes/static
cp your-image.png favicon.ico
cp your-image.png favicon-16x16.png
cp your-image.png favicon-32x32.png
cp your-image.png apple-touch-icon.png
cp your-image.png android-chrome-192x192.png
cp your-image.png android-chrome-512x512.png
